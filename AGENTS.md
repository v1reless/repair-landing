# Правила проекта

## Стек

- Лендинг: чистый HTML, CSS и JavaScript.
- Без фреймворков, CDN, сборщиков и внешних библиотек.
- Файлы лендинга — в корне проекта.
- Telegram-бот — в `telegram-bot/`, только встроенные модули Node.js.

## Код

- Комментарии на русском.
- Семантическая разметка: header, main, section, form, footer.
- CSS только в `style.css`, JS лендинга только в `script.js`.
- Не добавлять API-ключи, пароли и секреты в клиентский код.
- Токен Telegram-бота хранить только в `telegram-bot/.env`; не коммитить `.env`.
- Не устанавливать пакеты без разрешения.
- Пользовательский текст выводить через `textContent`, а не `innerHTML`.

## Дизайн

- Светлая тема, тёплый терракотовый акцент.
- Адаптивность: телефон, планшет, десктоп.
- Системные шрифты, без внешних картинок.
- Достаточный контраст текста и видимый фокус.
- Не превращать демо-карточки работ в фейковые отзывы или реальные кейсы.

## Форма

- Валидировать имя, телефон, услугу и согласие.
- Показывать ошибки конкретным полям.
- Не отправлять данные без согласия.
- В демо-режиме не сохранять персональные данные.
- Для реальной отправки использовать Telegram-бота, Formspree или другой серверный endpoint.
- Не отправлять токен бота в браузер и не подставлять его в HTML или `script.js`.

## Работа с проектом

- Перед крупными изменениями показывать план.
- Не удалять существующие файлы без предупреждения.
- После изменений кратко объяснять, что и зачем сделано.
